# Temporo

Учебный проект: 2D top-down шутер в духе Crimsonland на [Defold](https://defold.com/).

Репозиторий нужен, чтобы освоить два инструмента на одной игре.

- [evolved.lua](https://github.com/BlackMATov/evolved.lua) — архетипный ECS для Lua. Игровое состояние и логика живут в сущностях и системах.
- [Photon Fusion для Defold](https://defold.com/extension-photon-fusion/) — мультиплеер. Игроки собираются в лобби, меняют ник и отмечают готовность. Матч запускает хост, он же мастер-клиент.

Defold показывает игру и возит данные по сети. Спрайты рисуют то, что посчитал ECS. Отдельные game object'ы держат реплицируемые свойства Fusion. Мост в конце кадра записывает в них состояние владельца, а в начале кадра читает чужое состояние обратно в сущности.

Поле больше экрана, камера следует за игроком. Игрок ходит с клавиатуры и стреляет в сторону курсора. Снаряды летят с конечной скоростью. Враги выходят из спавнеров вдали от игроков и идут к ближайшему. Из них иногда выпадает другое оружие.
